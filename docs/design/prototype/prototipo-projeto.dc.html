Por que construí

A equipe recebia planilhas de coordenadas e abria uma a uma no editor de mapas para conferir se as áreas se sobrepunham. Levava uma tarde por lote. Detalhes do processo antigo estão no relatório de levantamento.

A primeira versão travava aos 8 mil pontos. O requisito era 40 mil, numa máquina de 2017.

O que muda

  • Renderização em canvas com agrupamento por nível de zoom
  • Recorte por polígono livre, com interseção calculada no navegador
  • Exportação do recorte em GeoJSON e CSV

Agrupamento

src/agrupar.tsTypeScript
// Agrupa pontos por célula de grade conforme o zoomexport function agrupar(pontos: Ponto[], zoom: number): Grupo[] {  const tamanho = 256 / 2 ** zoom;  const celulas = new Map<string, Ponto[]>();  for (const p of pontos) {    const chave = `${Math.floor(p.x / tamanho)}:${Math.floor(p.y / tamanho)}`;    celulas.set(chave, [...(celulas.get(chave) ?? []), p]);  }  return [...celulas.values()].map(criarGrupo);}

O tamanho da célula cai pela metade a cada nível de zoom, então o número de grupos visíveis fica estável enquanto o usuário navega.
