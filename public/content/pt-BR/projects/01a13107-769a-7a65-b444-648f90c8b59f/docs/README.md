## Contexto

Cada projeto da faculdade reimplementava botões, formulários e tabelas com aparência diferente.

## Meu papel

Fiquei com a interface, em dupla com a pessoa responsável pela API.

## Solução

Uma biblioteca de componentes acessíveis, documentada em Storybook e publicada para ser usada nos outros projetos.

## Decisões técnicas

| Decisão   | Motivo                                       |
| --------- | -------------------------------------------- |
| Storybook | Documentação e testes visuais no mesmo lugar |
| Vitest    | Testes rápidos para cada componente          |

## Resultado

Três projetos já usam a biblioteca no lugar de componentes próprios.
