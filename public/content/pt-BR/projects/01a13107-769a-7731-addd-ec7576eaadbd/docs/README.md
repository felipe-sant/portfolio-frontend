## Contexto

A clínica marcava consultas por telefone e perdia horários por falta de confirmação.

## Meu papel

Participei do projeto de ponta a ponta, em um time de três pessoas.

## Solução

Um site permite escolher o horário, e uma API em Java confirma por e-mail e atualiza o painel da recepção.

## Decisões técnicas

| Decisão     | Motivo                                      |
| ----------- | ------------------------------------------- |
| Spring Boot | Estrutura madura para a API e a validação   |
| PostgreSQL  | Restrições para impedir horários duplicados |

## Resultado

As faltas sem aviso caíram depois que a confirmação por e-mail entrou em uso.
