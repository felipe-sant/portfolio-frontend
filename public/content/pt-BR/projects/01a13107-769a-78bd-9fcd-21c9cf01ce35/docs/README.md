## Contexto

O estoque da cooperativa era controlado em planilha e só uma pessoa sabia atualizá-la.

## Meu papel

Participei do projeto de ponta a ponta, em um time de três pessoas.

## Solução

Um sistema web registra entradas e saídas e avisa quando um item chega ao nível mínimo.

## Decisões técnicas

| Decisão    | Motivo                                          |
| ---------- | ----------------------------------------------- |
| Angular    | Formulários e validação integrados ao framework |
| SQL Server | Banco já usado pela cooperativa                 |

## Resultado

Mais de uma pessoa passou a atualizar o estoque sem conflitos.
