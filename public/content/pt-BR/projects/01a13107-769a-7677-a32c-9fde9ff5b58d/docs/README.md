## Contexto

O estoque era comprado por estimativa, com sobras e faltas frequentes.

## Meu papel

Conduzi sozinho a análise dos dados, o modelo e a apresentação dos resultados.

## Solução

Um modelo treinado com o histórico de vendas prevê a demanda semanal e um relatório compara previsão e vendas reais.

## Decisões técnicas

| Decisão      | Motivo                                            |
| ------------ | ------------------------------------------------- |
| scikit-learn | Modelos de base fáceis de comparar                |
| Jupyter      | Exploração dos dados e relatório no mesmo caderno |

## Resultado

O erro médio ficou abaixo do da estimativa manual nas categorias mais vendidas.
