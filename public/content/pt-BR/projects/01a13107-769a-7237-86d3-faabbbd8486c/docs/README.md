## Contexto

As receitas da família estavam em cadernos e fotos soltas no celular.

## Meu papel

Fiz o projeto sozinho, do banco de dados à interface.

## Solução

Um aplicativo Android guarda cada receita com fotos e ingredientes e monta a lista de compras a partir delas.

## Decisões técnicas

| Decisão         | Motivo                                      |
| --------------- | ------------------------------------------- |
| Jetpack Compose | Interface declarativa com menos código      |
| Room            | Armazenamento local sem depender de conexão |

## Resultado

O álbum já reúne as receitas da família e segue em desenvolvimento.
