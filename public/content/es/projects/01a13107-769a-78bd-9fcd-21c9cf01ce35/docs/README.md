## Contexto

El inventario de la cooperativa se controlaba en una hoja de cálculo y solo una persona sabía actualizarla.

## Mi rol

Participé en el proyecto de punta a punta, en un equipo de tres personas.

## Solución

Un sistema web registra entradas y salidas y avisa cuando un artículo llega al nivel mínimo.

## Decisiones técnicas

| Decisión   | Motivo                                           |
| ---------- | ------------------------------------------------ |
| Angular    | Formularios y validación integrados al framework |
| SQL Server | Base de datos ya usada por la cooperativa        |

## Resultado

Más de una persona pasó a actualizar el inventario sin conflictos.
