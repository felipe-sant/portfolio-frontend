## Contexto

Las recetas de la familia estaban en cuadernos y fotos sueltas en el celular.

## Mi rol

Hice el proyecto yo solo, desde la base de datos hasta la interfaz.

## Solución

Una aplicación Android guarda cada receta con fotos e ingredientes y arma la lista de compras a partir de ellas.

## Decisiones técnicas

| Decisión        | Motivo                                        |
| --------------- | --------------------------------------------- |
| Jetpack Compose | Interfaz declarativa con menos código         |
| Room            | Almacenamiento local sin depender de conexión |

## Resultado

El álbum ya reúne las recetas de la familia y sigue en desarrollo.
