## Contexto

El inventario se compraba por estimación, con sobrantes y faltantes frecuentes.

## Mi rol

## Solución

## Decisiones técnicas

| Decisión     | Motivo                                              |
| ------------ | --------------------------------------------------- |
| scikit-learn | Modelos base fáciles de comparar                    |
| Jupyter      | Exploración de datos e informe en el mismo cuaderno |
