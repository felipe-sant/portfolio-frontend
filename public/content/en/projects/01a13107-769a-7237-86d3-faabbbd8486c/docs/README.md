## Context

The family recipes were in notebooks and loose photos on the phone.

## My role

I built the project on my own, from the database to the interface.

## Solution

An Android app stores each recipe with photos and ingredients and builds the shopping list from them.

## Technical decisions

| Decision        | Reason                                             |
| --------------- | -------------------------------------------------- |
| Jetpack Compose | Declarative interface with less code               |
| Room            | Local storage that does not depend on a connection |

## Outcome

The album already gathers the family recipes and is still in development.
