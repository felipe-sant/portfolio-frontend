## Context

The clinic booked appointments by phone and lost slots because of missing confirmations.

## My role

I took part in the project end to end, in a team of three people.

## Solution

A website lets patients pick a time, and a Java API confirms by email and updates the front-desk dashboard.

## Technical decisions

| Decision    | Reason                                      |
| ----------- | ------------------------------------------- |
| Spring Boot | Mature structure for the API and validation |
| PostgreSQL  | Constraints that prevent duplicate slots    |

## Outcome

No-shows dropped after email confirmation went live.
