## Context

The cooperative's inventory was tracked in a spreadsheet and only one person knew how to update it.

## My role

I took part in the project end to end, in a team of three people.

## Solution

A web system records stock in and out and warns when an item reaches its minimum level.

## Technical decisions

| Decision   | Reason                                        |
| ---------- | --------------------------------------------- |
| Angular    | Forms and validation built into the framework |
| SQL Server | Database already used by the cooperative      |

## Outcome

More than one person started updating the inventory without conflicts.
