## Context

Each college project reimplemented buttons, forms and tables with a different look.

## My role

I handled the interface, working in a pair with the person in charge of the API.

## Solution

A library of accessible components, documented in Storybook and published for use in the other projects.

## Technical decisions

| Decision  | Reason                                      |
| --------- | ------------------------------------------- |
| Storybook | Documentation and visual tests in one place |
| Vitest    | Fast tests for every component              |

## Outcome

Three projects already use the library instead of their own components.
