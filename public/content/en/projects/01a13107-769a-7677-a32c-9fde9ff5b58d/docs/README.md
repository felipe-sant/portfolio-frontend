## Context

Stock was bought by estimate, with frequent surpluses and shortages.

## My role

I handled the data analysis, the model and the presentation of the results on my own.

## Solution

A model trained on the sales history predicts weekly demand and a report compares the forecast with actual sales.

## Technical decisions

| Decision     | Reason                                           |
| ------------ | ------------------------------------------------ |
| scikit-learn | Baseline models that are easy to compare         |
| Jupyter      | Data exploration and report in the same notebook |

## Outcome

The average error was lower than the manual estimate in the best-selling categories.
